# E-Commerce Sales Dashboard (Excel)

## Project Overview
Interactive sales dashboard created in Microsoft Excel using Power Pivot, Pivot Tables, Pivot Charts, Slicers and Data Modeling.

## Features
- Sales Trend Analysis
- Category Analysis
- Region Analysis
- Top Selling Products
- Payment Method Analysis
- Customer Segmentation
- Ship Mode Analysis
- Monthly Order Trend
- Return Analysis

## Tools Used
- Microsoft Excel
- Power Pivot
- Pivot Tables
- Pivot Charts
- Slicers
